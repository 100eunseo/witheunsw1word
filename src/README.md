# lesson2_quiz_interactive.html 소스

배포되는 HTML은 여기서 생성한다. HTML을 직접 고치지 말고 이 파일들을 고친 뒤 다시 빌드할 것.

## 파일

| 파일 | 내용 |
|---|---|
| `vocab.py` | 단어 뜻 130 / 유의어 42 / 반의어 40 / 시험범위 밖 오답풀(EXT) 57 |
| `passage.py` | 본문 47문장 (영어 + 해석) + 문단 구분 |
| `blanks.py` | 본문에서 단어장 130개 단어를 찾아 빈칸 자리를 자동 추출 |
| `sim.py` | 단어 뜻 문제의 오답 선지 후보 계산 (정답이 둘이 되는 후보 제외) |
| `make_data.py` | 위 넷을 합쳐 `data.json` 생성 |
| `template.html` | 앱 화면·로직. `__DATA__` 자리에 data.json이 들어간다 |
| `build.py` | template.html + data.json → ../lesson2_quiz_interactive.html |

## 빌드

```bash
cd src && python3 make_data.py && python3 build.py
```

## 오답 선지 안전장치 (중요)

"정답이 둘"이 되는 사고를 막는 장치가 세 겹이다. 데이터를 고칠 때 반드시 유지할 것.

1. **의미 묶음(group)** — 같은 묶음끼리는 서로 오답 선지가 되지 않는다.
   한 단어가 묶음을 여러 개 가질 수 있다 (`"GROW|SPEED"` 처럼 `|`로 구분).
   유의어표와 반의어표의 묶음을 합쳐서 비교한다.
2. **뜻 겹침 제외** — 단어 뜻 문제에서 정답과 뜻 조각이 하나라도 겹치는 후보는 뺀다.
3. **파생어 제외** — 어근이 같은 단어(advance-ment / advance-d)는 서로 선지가 되지 않는다.

본문 빈칸은 드릴에서 첫 글자를 보여주므로 보기 오답을 첫 글자가 다른 단어로,
실전에서는 힌트가 없으므로 품사가 다른 단어로 뽑는다.

## 저장 방식

오답·진행 기록은 브라우저 localStorage에만 있다. 백엔드 없음.
학생 기기 안에만 남고 선생님은 볼 수 없다.
